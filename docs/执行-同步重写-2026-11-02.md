## 身份模型

- **账号**：`accounts(id, email UNIQUE NOCASE, display_name, password_hash?, is_admin, status, quota_bytes?, …)`。
  `password_hash` 可空：只用 GitHub 登录的账号没有密码。
- **会话**：`sessions(token_hash UNIQUE, account_id, kind = device | panel, device_id?, expires_at?, revoked_at?)`。
  客户端登录拿到不透明令牌 `ons_…`，请求时 `Authorization: Bearer`；服务端只存 `sha256`。
  移除设备 = 吊销它的会话；改密码 / 重置密码 = 吊销该账号全部会话。
- **密码**：`node:crypto` 的 scrypt（N=2¹⁵, r=8, p=1），格式 `scrypt$N$r$p$salt$hash`，不引新依赖。
- **第一个管理员**：服务端零账号时 `/admin` 显示初始化表单；之后永久关闭。CLI 保留 `create-admin` / `reset-password` 作为根信任通道。
- **邀请**：链接 `/join/<code>`，可绑定邮箱、角色、配额、有效期、次数；对方在网页里设密码或用 GitHub 接受。
- **端到端加密**：账号级「加密口令」，只在客户端派生（scrypt）出 `wrapKey`，服务端只存 `wrappedEncRoot` 与 KDF 参数。
  与登录方式无关。新设备用口令解锁，或用配对码从已解锁设备接收 `encRoot`。
