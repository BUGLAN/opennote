## 三、别回退的决定（都踩过坑）

- **不要拦 Ctrl/⌘ + C / V / X 的 keydown**：拦了浏览器就不派发剪贴板事件，也读不到系统剪贴板。
  复制粘贴走 `document` 上的 copy / cut / paste 监听，按「焦点是否在 `.canvas-root` 里」认领。
- **内部剪贴板靠「系统剪贴板文本」做标记**，不用自定义 MIME（平台差异少一层）：
  粘贴时系统文本与上次写入的相同 → 粘卡片本身，否则按系统内容建卡。
- **分组的 React Flow 渲染 key 叫 `canvasGroup`，不能叫 `group`**：叫 `group` 会被套上
  `.react-flow__node-group` 的默认皮肤（实线黑框、浅灰底、10px 内边距）。
- **`elevateNodesOnSelect={false}`**：z 序 = 数组序（JSON Canvas 规范）；开着它，选中的分组会盖住框里的卡。
- **分组节点 `zIndex: -1`**：React Flow 的连线默认画在所有节点下面，不压低分组，分组的半透明底色会把框里的连线罩淡。
- **连线桩的强调色不能挂在 `.connectionindicator` 上**：React Flow 给所有可连的桩常挂这个类。
  显隐用 `:hover` / `.selected` / 根节点的 `is-connecting`、`is-multi-select`。
- **选中态是一条边框**：卡片自身边框换实色强调色 + 贴一圈同色 1px；不要用「半透明描边 + 淡色光环」，
  看上去是两道框。分组只给虚线换色。
- **箭头颜色在渲染前派生**（`displayEdges`），状态里不存 marker：选中变化散落在很多路径里，
  只有这样箭头才能跟着选中态、改色、开关箭头立即更新。
- **分组子节点按「完整落在框里」判定**，拖动开始时算一次；被拖的选区本身要排除，否则移两遍。
- `onConnectEnd` 在重连（拖边端点）时也会触发，而且先于 `onReconnectEnd`：靠 `reconnectingRef` 区分，
  否则重连拖到空白处会凭空建卡。
