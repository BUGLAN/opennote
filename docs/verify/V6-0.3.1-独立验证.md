## 2. 我先修自己的两个问题（都是自曝）

### 2.1 `C-6f` 的取词器漏洞：**整张「一行一条」的表被吞成一次匹配**

**问题**：旧取词器 `/["']IMP-(\d{4})["']\s*:\s*\{([\s\S]{0,400}?)\n\s*\}/g` 要求 `{` 与 `}` 之间**有换行**，
而 `electron/bridge.cjs` 的 `ERROR_TABLE` 是**一行一条**（`'IMP-1001': { http: 503, …, userMessage: '…' },`），
于是**整张表被吞成一次匹配** —— 这条「多产地护栏」自己静默漏掉了绝大多数产地。

**我先量了，再改**（诊断脚本在 `%TEMP%\opennote-v2\probe-extract.cjs`，不属于仓库）：

```
$ node probe-extract.cjs E:\repo\opennote
bridge      键位码数=34 | 旧取词= 1 | 新取词=34 | 新取不到值的=0 | 旧漏掉的=33
envelope    键位码数=17 | 旧取词=15 | 新取词=17 | 新取不到值的=0 | 旧漏掉的=2
inbox       键位码数=24 | 旧取词=24 | 新取词=24 | 新取不到值的=0 | 旧漏掉的=0
ext-errors  键位码数=33 | 旧取词=32 | 新取词=30 | 新取不到值的=0 | 旧漏掉的=1
ext-dist    键位码数=33 | 旧取词=32 | 新取词=30 | 新取不到值的=0 | 旧漏掉的=1
```

> 实测：**bridge 只比了 1/34（漏 97%）**，与 Lead 的判断一致；`envelope.ts` 另漏 2 个。
> `ext-errors` 的「30 + 3」不是漏：`IMP-1005 / IMP-3004 / IMP-3005` 在表里**显式标了 `userMessage: null`**
> （按契约对用户不可见，`extension/src/lib/errors.ts:238` 的注释就是这么写的），我把它记成「按契约不可见」而不是「漏」。

**改法**：换成**括号配平扫描** `balanceCopies()` —— 定位 `"IMP-xxxx":` 键之后，
若值是 `{` 就配平到配对的 `}`（跳过字符串字面量里的括号），若值是字符串字面量就直接取。
不依赖任何缩进/换行风格。（我先写过一版「窗口到下一个键」，它会把文件后半段无关的 `userMessage:`
—— 例如 `bridge.cjs:787` 那句「配对功能已在 0.3.1 删除」的说明 —— 吸进没有 `userMessage` 的记录里；
配平扫描没有这个问题，所以最终采用配平版。）

**覆盖率现在每次都打印**（不再只藏在 okDetail 里）：

## 5. `EX-6` 误报的修正（Lead 指定）+ 变异验证

**Lead 的复核**：`FAIL [EX-6] extension/dist/popup/popup.html:70 含远程 URL` 是误报，判据要收窄到「真的远程引用」。

**我实测到的那一行**（与 Lead 看到的是同一行，但命中原因不同，据实记录）：

```
$ (Get-Content extension/dist/popup/popup.html)[69]
<div class="clip__row"><label for="propUrl">网址</label><input id="propUrl" data-prop="source.url"
 class="field" placeholder="https://example.com/posts/local-first" autocomplete="off" spellcheck="false"></div>
```

真正命中旧判据（非注释行出现 `https?://`）的是 **`placeholder="https://example.com/…"`** ——
它是**表单空值时的灰色示例字**，不会发起任何请求；Lead 注意到的 `data-prop="source.url"` 是**字段路径**，
本身不含 `://`。两者都不该算「远程引用」。

**新判据**（只看**真的会引发网络加载/请求**的东西）：
① 资源属性 `href/src/srcset/action/poster` 的值；② CSS `url(...)`；
③ `fetch/importScripts/XMLHttpRequest.open/import` 的参数；
④ 脚本里的 URL **字符串字面量**（`extension/**` 的 `.js` 整体按脚本扫，HTML 只扫 `<script>` 块内）。
并且要求 `https?://` 后面跟**真正的主机名首字符**（`opennote://settings/import` 这类自有协议、
`http(s):// 开头` 这类说明文字都不算），回环 `127.0.0.1`/`localhost` 不算远程。
非资源属性（`placeholder`/`data-*`/`title`/`aria-*`/`value`）里的 URL 只记 `INFO [EX-6′]`，**不判失败**。

**两种输出（Lead 要求的变异验证）**：


## 10. 可复用护栏模式（本轮沉淀）

1. **`S7.0` 静态 API 比对**：从 `main.cjs` 的**非注释行**里抽出它用到的 `electron` API（`<ns>.<a>` 与 `<ns>.<a>.<b>`），
   逐个走进打桩对象链，缺哪个**报精确名**（不是「场景崩了」）。本轮它又扩到 `ELECTRON_NAMESPACES`：
   `main.cjs 用到 25 个 API，打桩全部具备`。
   价值：上一轮 `app.requestSingleInstanceLock is not a function` 让 PASS 从 81 **静默**掉到 67。
2. **`withCoverageGuard(label, expectedIds, body)`：未报告即 FAIL**。
   场景中途抛异常时，把**没报告过的检查 id** 逐条报 FAIL（`S10-crash` + `S10-coverage：缺失 S10.6…S10.11`）。
   本轮它当场抓住了我自己的 `ReferenceError: info is not defined` ——
   **「PASS 从 81 静默掉到 67 比报错危险得多」**，这条护栏就是为这句话写的。
3. **`C-6h` 取词覆盖率自检**：护栏自己证明「我到底比了几个码/几条记录」。
   规则：每个键位码必须有归宿（取到值 or 显式 `null`），否则 FAIL 并列出未认领清单。
   **它是取词器漏洞唯一有效的补丁** —— 没有它，`C-6f` 会在「只比 1/34」的状态下**显示绿色**。
4. **内存变异自检（三种形态）**：
   - 文案变异：`--mutate-copy=<producer>` / `--mutate-copy=<producer>:<CODE>`（精确到表中间那一行）
   - 产物变异：`--mutate-ex6=remote-src|eval`（在内存里给 html 塞远程 script / eval）
   - 防线变异：`loadMutatedModule()` 用 **`new Module()` + `_compile(变异源码, 真实绝对路径)`** 重编译
     `bridge.cjs`，再起一座桥实测（来源放行 / pair 静默 404 / 令牌校验恒真）
   **铁律**：变异没命中源码时必须**报错**，不能当成「护栏检测到了」（`loadMutatedModule` 命中失败返回 `null`，
   调用方记 `**变异没命中源码**，本条自检失效`）。
5. **配平式取词**（§2.1）：不依赖缩进/换行/单行多行风格；「窗口到下一个键」这种写法会把远处无关字段吸进来。
6. **真 HTTP + 一次性连接**：`http.request` + `agent:false`（`fetch` 不让设 `Origin`；
   keep-alive 长连接会在桥 `stop()` 时抛 `ECONNRESET`，把一次成功的请求变成场景崩溃）。
7. **阴性对照**：每个「A 应该发生」的断言旁边放一个「把它改成 B 就不该发生」的对照
   （`selection:false → pending` vs `selection:true → appended`；同一令牌 2xx vs 另一个令牌 401；
   `in-app` 通道 vs 外部通道）。没有对照的绿灯，通常只是**恒绿**。
