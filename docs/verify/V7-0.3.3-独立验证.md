## §G 本轮沉淀的护栏模式（可复用）

1. **`mutationLanded()`：变异必须先证明落地** —— 命中处数 + 前后 sha256；0 命中 → `NO_EFFECT` + **退出码 2**，不进红绿判定（对**检查器自己**同样适用）。
