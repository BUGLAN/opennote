视觉禁区（验收硬指标）

用户的验收原话是「希望这个 UI 能够简洁美观，能够符合现在的应用」。下面是这套设计稿明确排除的做法。

不要 大色块渐变、彩色英雄区、玻璃拟态卡片 全站唯一渐变是主题色板上的小圆点
不要 emoji 装饰 图标只用项目现有 Icon 名称
不要 彩色圆角卡片堆叠 卡片只有一种形态：1px 描边 + 8px 圆角，一次最多 3 张
不要 SaaS 仪表盘风：统计卡片、环形进度、彩色图标块 导入是安静的后台行为
不要 成功绿 / 警告黄 / 失败红语义色 危险与失败一律用 --accent，成功用 --ink 反色药丸
不要 错误抖动、闪红、扫光 错误靠一句完整的中文和位置区分
不要 列表逐条入场动画、数字徽标弹跳 会打断写作
不要 搬运式加载遮罩 加载只发生在被操作的那个控件上
