键盘可达性与无障碍

Tab 顺序状态芯片（只读，tabindex="-1"）→ 分段控件 → 标题输入 → 落点 → 标签 → 主按钮 → 「⋯」菜单
Enter在标题或标签输入框内直接提交，等价于点主按钮
Esc关闭弹窗（浏览器原生行为，不拦截）
分段控件role="radiogroup" + role="radio"，←/→ 切换，不必按 Tab 穿过两个按钮
加载态主按钮 aria-busy="true"；状态芯片 role="status" aria-live="polite"
对比度错误句与状态文字一律用 --ink 或 --accent；--ink-3 只用于时间戳这类补充信息（约 3.2:1，低于 AA）
动效只用 rise / fade / pop / pulse 与 120·220·460ms；prefers-reduced-motion 全局降级（本文件已内联）
