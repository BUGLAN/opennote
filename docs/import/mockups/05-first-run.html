如实描述平台差异（原则 P5 / FR-56 / FR-66）

三种文件系统后端能力不对等：只有 Electron 桌面版能「外部进程直接落盘」。所以界面必须说清每个平台各自能做到什么，不含「都支持」这种含糊说法。

桌面版三种通道全可用：本地接口 + 命令行 + 收件箱；插件可以投递。
Chrome / Edge 网页版（FSA）没有本地接口；Opennote 窗口在场时可通过页面内桥投递（「已把这段内容发送给已打开的 Opennote 窗口。」），属 P0；窗口不在场时明确告知不可用（IMP-4006）。
其它浏览器（OPFS）页面内桥为 P1 且绑定 D12 门禁；门禁未过时文案表达「尚未开放」而不是「不支持」——能力存在，只是还没放行。
移动端P0 不出现任何入口（不做假入口）；给出降级路径「手机上暂时不能直接剪藏到 Opennote。可以复制正文，在 Opennote 里新建笔记粘贴。」P1 由分享面板承接。

命令面板：新增分组「导入」（FR-74）

沿用现有命令注册表结构，快捷键与设置面板共用同一份定义，不会出现「菜单里有、面板里没有」的漂移。

键盘可达性与无障碍

打开时焦点落在第一张卡片内的「怎么安装」按钮（不是弹窗本身）；Esc 可关闭，等于「稍后再说」。
通知类引导标题不是 role="alert"；开启成功的反馈由状态芯片（role="status" aria-live="polite"）承担。
危险操作「重新生成访问令牌」沿用现有 askConfirm 的 danger 样式与焦点管理。
动效降级prefers-reduced-motion 下动画与过渡降为 0.01ms（本文件已内联）；引导首屏的 rise 460ms 也随之失效，静态呈现仍完整可读。
对比度卡片说明文字用 --ink-3（约 3.2:1，低于 AA），因此卡片标题与状态值一律用 --ink / --ink-2；错误句用 --ink + 左侧强调色竖条。
